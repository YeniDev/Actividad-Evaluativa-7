Uso de cajas flotantes y estilos CSS

Introducción a las cajas flotantes (div)

Las cajas flotantes permiten distribuir el contenido de una página web en distintas áreas.

La propiedad float: left; ubica una caja hacia la izquierda de su contenedor.

Uso de la propiedad float

La propiedad float: right; ubica esta caja hacia el lado derecho.

El uso de clearfix permite que el contenedor principal abarque correctamente las dos cajas flotantes.
